# todo_list_fullstack

The goal of this project is to learn how flutter and python can be combined to create a simple application like this To-Do List.

## Frontend Technologies

* **[Flutter](https://flutter.dev/)**: Main framework for mobile/cross-platform application development.
* **[Dart](https://dart.dev/)**: Programming language used.
* **[Riverpod](https://riverpod.dev/)**: Robust and reactive state management.
* **[Dio](https://pub.dev/packages/dio/)**: Powerful HTTP client for communication with the backend API.

## Backend Technologies

* **[FastAPI](https://fastapi.tiangolo.com/)**: Main framework for API development.
* **[SQLAlchemy](https://www.sqlalchemy.org/)**: ORM for database management and mapping.
* **[PostgreSQL](https://www.postgresql.org/) (`psycopg2`)**: Relational database.
* **[Pydantic](https://docs.pydantic.dev/)**: Data validation and settings management using Python type annotations.
* **[Uvicorn](https://www.uvicorn.org/)**: ASGI server for running the application.
